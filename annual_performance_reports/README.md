# Federal Grant Performance Reporting — GPRA Scoring Pipeline

Automated scoring and reporting of **Government Performance and Results Act (GPRA)** measures for two federal school mental health grant programs. This pipeline processes Annual Performance Report (APR) data, evaluates grantee performance against targets, and produces summary statistics for federal reporting.

---

## Programs

| Program | Full Name | Grantee Type |
|---------|-----------|--------------|
| **MHSP** | Mental Health Service Professionals | Higher education institutions |
| **SBMH** | School-Based Mental Health | K–12 education agencies |

## Notebooks

### `metrics_apr_report_gpra2.ipynb` — Grantee Target Scoring

Processes Year 2 APR data for MHSP and SBMH grantees.

**Key steps:**
- Standardizes column names from raw Smartsheet exports
- Parses GPRA 3 ratio strings (e.g., `"49,786/256"`) into decimals
- Replaces non-numeric sentinel codes (`999`, `NR`, `N/A`) with `NaN`
- Scores each grantee by comparing actual vs. target values across all GPRA measures
- Applies measure-specific scoring logic (GPRA 4 attrition: met when `actual ≤ target`)
- Flags grantees meeting ≥ 2 of their performance targets
- Exports grantee-level results and program-level summary statistics

**Sample output (`gpra_summary_stats.json`):**
```json
{
  "percentage_grantees_meeting_goals": 80.65,
  "percentage_mhsp_meeting_targets": 69.93,
  "percentage_sbmh_meeting_targets": 97.89,
  "mhsp_grantees_meeting_targets": 107,
  "sbmh_grantees_meeting_targets": 85,
  "total_mhsp": 153,
  "total_sbmh": 95
}
```

### `metrics_apr_report_gpra3.ipynb` — TA Session Satisfaction

Summarizes post-session survey data from Technical Assistance (TA) sessions.

**Key steps:**
- Recodes Likert-scale text responses (agreement and satisfaction scales) to numeric 1–5
- Assigns survey responses to sessions by matching submission timestamps to anchor dates (±2/+3 day window)
- Groups survey items into three constructs: Quality, Usefulness, Relevance
- Calculates the percentage of respondents scoring ≥ 4 per construct per session
- Exports a session-level summary table

**Survey constructs:**

| Construct | Items |
|-----------|-------|
| Quality | Presenter knowledge, clarity, satisfaction |
| Usefulness | Applicability, ease of use, effectiveness |
| Relevance | Novelty and informational value of content |

## Usage

1. Place input Excel files in the `data/` directory (see structure above)
2. Open the relevant notebook in Jupyter
3. Run all cells — outputs are written to `output/`

To change the data directory, update `DATA_DIR` in the Setup cell of each notebook.

---

## Data Privacy

All data in this repository are **synthetic and anonymized**. Grantee names, grant IDs, and personnel information have been replaced with fictional values. Numeric performance data preserve the statistical structure of the original dataset.
